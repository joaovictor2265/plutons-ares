# Plutons Ares

Plutons Ares is an independently developed Windows desktop launcher and profile manager for Minecraft Java Edition. The application is currently under development.

## Features

- Separate game profiles with configurable Minecraft and mod loader versions.
- Mod and modpack management with CurseForge and Modrinth integration.
- Skin previews and skin management.
- Profile backups, diagnostics, and game logs.

## Microsoft sign-in

Microsoft sign-in uses the OAuth device authorization flow. Users enter their credentials on Microsoft's website. The launcher requests Xbox authorization and Minecraft Services access to verify Minecraft Java Edition ownership and retrieve the player's Minecraft profile.

Minecraft Services API access for this application's Client ID has not yet been approved. An application review request is being prepared. Microsoft account sign-in is not yet fully operational.
